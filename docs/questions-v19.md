# Dr. 실리콘 질문·답변

첫 줄은 질문하기 / 내 질문·답변 / 자주하는 질문, 둘째 줄은 튜토리얼 다시보기입니다. 기존 첫걸음 튜토리얼 흐름과 FAQ 내용은 유지합니다.

## 최초 연결

1. **현재 운영 API의 Apps Script 프로젝트**를 엽니다. 기존 전체 코드를 `Code_v19.gs`의 전체 내용으로 교체합니다. 이전 전체 번들과 Questions.gs를 중복 설치하지 마세요. v19에는 v18의 자료별 책 보상 기능도 포함되어 있습니다.
2. 함수 목록에서 **setupQuestionsV19**를 선택하고 실행합니다. 처음에는 Google 권한 승인이 필요합니다.
3. 실행 로그에 표시되는 **질문답변 시트 URL**을 엽니다. 새 파일 `도핑 히어로즈_질문답변`이 생성되고 `QA_SPREADSHEET_ID` 속성으로 자동 연결됩니다. 같은 함수를 재실행해도 기존 파일과 질문을 유지합니다.
4. 이 새 파일만 필요한 조교에게 **편집자**로 공유합니다. 일반 액세스는 제한됨을 유지합니다. 운영·학습 콘텐츠 파일이나 API Apps Script 프로젝트를 공유할 필요는 없습니다.
5. 배포 → 배포 관리 → 현재 게임이 사용하는 배포 편집 → **새 버전** → 배포를 선택합니다. 기존 배포를 업데이트하면 URL이 유지됩니다. 새 배포를 별도로 만들었다면 새 `/exec` URL을 게임에도 연결해야 합니다.
6. 게임을 새로고침해 Dr. 실리콘에서 질문을 등록합니다. 내 질문·답변에서 새로고침을 누르면 조교가 게시한 답변이 표시됩니다.

## 조교의 답변 작성

Questions 탭의 **answer**에 답변, **answeredBy**에 표시할 이름을 입력한 뒤 **status**를 **답변완료**로 바꿉니다. 답변이 비어 있으면 게시하지 않습니다. **작성중**이나 **답변대기**인 답변은 학생에게 보이지 않습니다. 게시를 철회하려면 상태를 작성중으로 바꿉니다. 답변 수정 시각은 설치형 편집 트리거가 서울 시간으로 기록합니다.

| 열 | 의미 |
| --- | --- |
| questionId | 중복 등록을 막는 고유 질문 ID |
| studentId / studentName | 로그인 정보로 서버가 확인한 질문자 |
| stage | 일반 질문 0, 스테이지 질문 1–12 |
| subject / question | 제목 / 질문 본문 |
| answer / answeredBy / status | 조교가 편집하는 답변 / 답변자 / 공개 상태 |
| createdAt / answeredAt | 질문 등록 / 답변 수정 시각, 서울 시간 |

학생에게는 인증된 본인 질문만 반환하며, 작성 중 답변과 다른 학생의 정보는 반환하지 않습니다. 학생은 답변을 입력하거나 공개 상태를 바꿀 수 없습니다. 답변은 HTML로 실행하지 않고 일반 텍스트로 표시합니다. 질문은 마지막 행에 추가하고 게임에서는 최신순으로 30개씩 조회합니다. 답변 조회는 메뉴를 열거나 새로고침할 때 실행합니다.

조교는 질문답변 파일의 모든 질문을 볼 수 있으므로 이 파일은 담당 교수·조교에게만 공유합니다. 자동 생성 열, 헤더 이름, questionId는 변경하지 마세요. 운영 데이터 초기화는 질문답변 파일을 삭제하지 않습니다.

## 검증과 배포 범위

로컬 테스트는 인증별 질문 분리, 비공개 초안, 중복 요청, 수식 입력 방지, 페이지 나누기, 답변 시각을 확인합니다. 실제 시트 생성·권한 승인·조교 공유·Apps Script 배포는 관리자 계정에서 위 단계를 진행해야 합니다.
