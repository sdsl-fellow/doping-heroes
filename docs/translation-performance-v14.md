# 번역 퀴즈 응답 개선 v14

정답은 계속 서버에서 판정합니다. 브라우저에는 제출 전 정답·해설을 보내지 않습니다.

- 문제은행은 서버 내부에서 60초간 캐시합니다. 캐시 오류·만료 시 시트를 다시 읽습니다. 이미 시작한 회차는 기존 문제 스냅샷으로 판정합니다.
- 정답과 보상, 문제별 누적 횟수는 Students.saveJson 한 행에 함께 저장하고 flush한 뒤 응답합니다. 동일 답안 재전송은 기존 결과를 반환하며 보상을 다시 지급하지 않습니다.
- TranslationProgress 전체 조회·행별 쓰기·정렬은 답안 응답 경로에서 제거했습니다. 다음 회차 시작 시 이전 답안을 하나씩 재집계하던 작업도 제거했습니다.
- 1분 주기의 syncTranslationProgress 트리거가 Students의 확정 기록을 읽어 집계를 일괄 갱신합니다. 최신 답안 순으로 정렬합니다. 트리거 실행 지연이나 잠금 경합에 따라 실제 반영에는 더 걸릴 수 있습니다.
- durable dirty marker는 보상 저장 전에 설정합니다. 집계 실패 시 유지되며 다음 실행에서 복구합니다. 캐시는 기록 보존에 사용하지 않습니다. 작업은 기존 공통 잠금을 사용합니다.
- setup 미실행 시 v13의 동기 집계 방식으로 작동합니다. 다른 학습·인벤토리 기능은 변경하지 않습니다.

## 적용

1. 기존 Apps Script 프로젝트의 전체 코드를 Code_v14.gs로 교체합니다. 기존 속성, 운영 시트 연결은 유지합니다. Reporting.gs/TranslationQuiz.gs를 중복 추가하지 마세요.
2. 편집기에서 setupTranslationPerformanceV14를 한 번 실행하고 트리거 권한을 허용합니다. v13 집계 설정이 없다면 기존 setupReportingV13이 먼저 실행됩니다. 반복 실행해도 트리거는 하나만 유지합니다.
3. 기존 웹 앱 배포를 편집하여 새 버전으로 배포합니다. 기존 URL 유지 시 게임 주소 변경이 필요 없습니다.
4. 번역 정답 제출 직후 게임 보상을 확인하고, 잠시 후 TranslationProgress의 누적 기록과 최신순 정렬을 확인합니다.

시트 문제 수정은 캐시가 만료된 후 새 회차부터 반영됩니다. 즉시 반영하려면 clearTranslationQuestionCache를 편집기에서 실행하세요. 시작된 회차의 정답은 중간에 바뀌지 않습니다.

## 검증 범위

Node VM 테스트: 제출 전 정답 비공개, 중복 요청 보상 1회, 복습 보상 1/10, 동기 집계 미호출, 캐시 적중/실패, 집계 최신순/재시도/손상 데이터 방어. 실제 지연 감소량 및 30명 동시 접속 성능은 새 Apps Script 배포 후 실측이 필요합니다. Apps Script 실행·통신 시간 자체가 사라지는 것은 아닙니다.
