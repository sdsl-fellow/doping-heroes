# Code_v20.gs 배포

1. 게임이 연결된 **기존 Apps Script 프로젝트**를 엽니다. 새 프로젝트를 만들면 기존 스크립트 속성과 학생 로그인 토큰이 이어지지 않습니다.
2. 편집기의 기존 전체 `Code.gs` 내용을 지우고 `google-apps-script/Code_v20.gs` **전체 내용**을 붙여넣고 저장합니다. `Code_v19.gs`, `Questions.gs` 등 이전 전체 번들을 같은 프로젝트에 함께 설치하지 마세요.
3. 프로젝트 설정의 `SPREADSHEET_ID`가 Roster/Students가 있는 운영 시트를 가리키는지 확인합니다. 배포만 하는 데 `setupDopingHeroes()`나 학생 기록 초기화 함수를 다시 실행할 필요는 없습니다.
4. **배포 → 배포 관리 → 게임이 사용 중인 배포 수정 → 버전: 새 버전 → 배포**를 선택합니다. 웹 앱 URL과 실행 사용자/접근 권한은 기존 작동하던 설정을 유지합니다.
5. 해당 `/exec` URL을 시크릿 창에서 열어 `apiVersion:20`과 `release:v20-roster-identifiers`가 포함된 JSON을 확인합니다.
6. 게임을 새로고침한 뒤 Roster A열에 있는 ID로 수강생 확인을 합니다.

Roster는 A열 `studentId`, B열 `name`입니다. 일반 학번은 기존대로 8자리이며, 조교/특별 수강생 ID는 영문·숫자·`-`·`_` 1~20자를 사용할 수 있습니다. 영문은 대소문자를 구분하지 않습니다. 앞에 0이 있는 ID나 15자리보다 긴 숫자는 입력 전에 A열을 **일반 텍스트**로 지정해 원래 값을 보존하세요. 숫자로 저장하면서 사라진 앞자리 0은 코드에서 복원할 수 없습니다. 관리자 ID `099746`은 예약되어 있습니다.
