# 자료별 낡은 책 완독 보상

Stage 1 자료 1과 자료 2의 완독 및 경험치 보상은 독립적입니다. 각 자료를 마지막 장까지 읽고 완독하기를 누르면 기존 책 보상량을 자료별 최초 한 번 지급합니다.

`saveJson.readBookSources`에 자료 ID를 저장합니다. 기존 `readBooks`는 책을 읽은 스테이지 목록으로 유지합니다. 자료별 기록이 없는 과거 데이터의 Stage 1 완독은 `SE01-CRYSTAL-2026`에만 연결하며, `SE02-ATOMS-2026`은 자동 완료하지 않습니다. 경험치를 소급 추가하거나 초기화하지 않습니다. 기존 학습 초기화 함수는 두 기록을 함께 비웁니다.

## 서버 적용

1. 현재 Apps Script 프로젝트의 전체 번들 코드를 `Code_v18.gs` 내용으로 교체합니다. 같은 함수를 가진 이전 전체 번들을 함께 두지 마세요.
2. 배포 관리에서 게임이 사용 중인 웹 앱 배포를 편집하고 새 버전으로 업데이트합니다. 이 방법은 기존 URL과 Script Properties를 유지합니다.
3. 게임을 새로고침합니다. API 버전 18을 확인하면 Stage 1 자료별 완독 버튼이 활성화됩니다. 별도 setup 또는 초기화 실행은 필요 없습니다.

번역 퀴즈 자료 2의 출처는 화면에서 `[SE] 02. Atoms and Electrons`로 통일합니다. 시트나 진행 중 회차에 남은 이전 제목에도 동일하게 적용됩니다.
