# v21 스테이지 퀴즈 일괄 준비

- 기존 Apps Script 프로젝트의 `Code.gs`를 `google-apps-script/Code_v21.gs` 전체 내용으로 교체해 저장하고, **기존 웹 앱 배포를 새 버전으로 갱신**합니다. 새 프로젝트를 만들거나 `setupDopingHeroes()`를 실행할 필요는 없습니다. `SPREADSHEET_ID`와 `CONTENT_SPREADSHEET_ID`는 유지합니다.
- 현재 게임 URL의 `/exec` GET 응답에 `apiVersion: 21`, `release: v21-stage-quiz-batch`가 나오는지 확인합니다. 게임 화면을 새로고침합니다. 이전 서버에서는 스테이지 일반 퀴즈를 시작할 수 없도록 보호합니다.
- 관문 입장 직후 `Quiz_01`~`Quiz_12` 중 해당 스테이지 탭의 활성 문제를 한 요청으로 받습니다. Stage 1의 번역 퀴즈도 입장 후 기존 5문제 회차를 미리 준비합니다.
- 일반 퀴즈는 그 입장 회차의 모든 문제를 정답으로 풀어야 스테이지 완료와 기존 스테이지 보상을 한 번 기록합니다. 현재 활성 문제가 1개면 1개를 맞히면 완료됩니다. 오답은 다시 시도할 수 있습니다. 정답·해설은 정답 확인 전 브라우저로 전송하지 않습니다.
- 부분 풀이 기록은 해당 브라우저의 열린 스테이지 세션에서 유지됩니다. 새로고침하거나 30분 서버 세션이 만료되면 완료하지 못한 회차는 다시 시작합니다. **이미 완료한 스테이지 기록과 보상은 유지**됩니다.
