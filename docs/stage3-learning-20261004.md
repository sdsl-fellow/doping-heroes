| 자료 | 강의자료 | 책 분량 |
| --- | --- | --- |

| 2 | [SE] 03. Energy Bands and Charge Carriers in Semiconductors (2) | 12장 |

자료 2는 이전에 제공된 `(2) - no time.pdf` 버전, 자료 3은 이번에 제공된 `Semiconductors(1).pdf`를 사용했습니다. 각 노트에 원본 PDF 쪽수를 표시합니다. 강의의 개념을 요약하며, 실험 연결 장의 100 nm·Nd = 10¹⁶ cm⁻³ 조건은 게임 교육용 설정입니다.

자료 1의 ID는 기존 `STAGE-3-BOOK-1`을 유지합니다. 기존 Stage 3 완독 기록은 자료 1로 처리하며 중복 보상을 지급하지 않습니다. 자료 2·3은 `STAGE-3-BOOK-2`, `STAGE-3-BOOK-3`으로 독립적으로 기록합니다. 각 자료의 최초 완독 보상은 기존 Stage 3 책 보상과 같습니다.

## 콘텐츠 시트 적용

일반 퀴즈 CSV는 45문항(자료별 15문항), 번역 CSV는 60문항(자료별 용어 10·문장 10문항)입니다. 문제·정답은 다운로드 파일과 비공개 학습 콘텐츠 시트에서 관리하며 공개 저장소에 넣지 않습니다.

1. `Quiz_03`과 `Translation_03`의 기존 데이터를 별도로 보관한 뒤, 각 CSV를 표로 열어 해당 탭의 A1부터 헤더와 함께 붙여넣습니다. 기존 데이터 행을 비워 새 문항 뒤에 이전 문항이 남지 않도록 합니다. 다른 탭은 변경하지 않습니다.
2. CSV의 `questionId`는 재편집해도 유지합니다. `active`는 TRUE입니다. `Quiz_03`은 기존 15열, `Translation_03`은 기존 16열 형식입니다.
3. 현재 운영 중인 Apps Script 프로젝트의 기존 전체 코드 파일을 제공한 `Code_v25_Stage3_20261004.gs` 내용으로 교체합니다. 같은 코드를 별도 파일에 추가하지 않습니다. API 버전은 25, 기존 운영·콘텐츠 시트 ID 및 PIN 관련 스크립트 속성은 유지합니다.
4. `setupStage3Learning()`을 실행합니다. 일반 45개·번역 60개가 확인되면 기존 웹 앱 배포를 새 버전으로 수정하여 기존 URL을 유지합니다. `setupDopingHeroes()`나 학생 기록 초기화·마이그레이션 함수는 실행하지 않습니다.
5. 게임을 새로고침합니다. 서버가 `translationStages: [1,2,3]`을 반환하면 Stage 3 PC가 활성화됩니다. 기존 서버에서는 Stage 3 번역 기능이 준비 중으로 유지됩니다.

일반 퀴즈의 도핑 보상은 기존 Stage 3 퀘스트와 동일하고, 코인은 30입니다. 현재 서버는 활성 일반 문항을 모두 맞혔을 때 Stage 보상을 최초 1회 지급합니다. 45개 문항에 각 30코인을 지급하는 구조가 아닙니다. 번역은 문항별 최초 정답에 도핑 약 8.19×10¹² cm⁻³·10코인, 복습에는 보상 없이 동작합니다. 이후 보상 값을 조정할 때 일반 퀴즈의 보상 열은 모든 행에서 동일하게 유지합니다.

## 검증

- 타입 검사 및 프로덕션 빌드, 전체 Node 테스트 통과.
- 실제 Apps Script의 문항 검증 함수로 CSV 45·60행, ID·보기 중복, 출처·정답·보상·종류 확인.
- Stage 3 자료별 완독 보상, 기존 기록의 중복 지급 방지, 저장 형식 왕복 확인.
- Stage 3 번역 시작·정답·재시도·다른 Stage 문제 토큰 거부 및 저장 후 PIN 필드 유지 확인.

운영 Google Sheet 붙여넣기와 Apps Script 웹 앱 버전 갱신은 사용자가 수행합니다. 저장소의 수정만으로 Google Apps Script 배포가 갱신되지는 않습니다.
