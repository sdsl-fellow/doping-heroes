# Stage gateways v4

Twelve transparent sprites generated with the built-in image generation tool, one call per stage. Runtime assets: public/gateways-v4/stage-1.webp through stage-12.webp. 256×256 RGBA WebP displayed at 112×112; source transparency preserved. Combined payload 384234 bytes. World positions, interaction zones, and access logic are unchanged. Explicit gatewayImage paths replace interior-art frame reuse. Stage 1's redundant crystal overlay is removed.
